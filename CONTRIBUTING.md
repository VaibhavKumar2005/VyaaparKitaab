# Contributing to VyaparKitaab

Thanks for your interest! A few quick guidelines:

- Fork the repo and create feature branches.
- Follow PEP 8 for Python code and keep functions small and testable.
- Write tests for new functionality and run `pytest` before submitting PRs.
- Update `README.md` or `docs/` when you add or change features.
- Open a pull request describing the change and link any related issue.

If you want help getting started, open an issue with "good first issue" in the title.

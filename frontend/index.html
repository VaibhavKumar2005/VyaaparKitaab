MSME Digital Notebook

VyaparKitaab

A simple, explainable, and privacy-conscious business notebook for Indian MSMEs. It helps manage invoices, customers, inventory, and OCR-based document scanning in one place.

Problem

Manual bookkeeping and scattered records make daily operations slow and error-prone.

Solution

A focused app for record management, document scanning, and business visibility.

Why this project

It is intentionally small enough to explain in a presentation, but complete enough to demonstrate real product thinking, backend APIs, data storage, OCR integration, and deployment.

Core modules

  • Login and role-based access
  • Customer and supplier records
  • Invoice and tax document scanning
  • Inventory tracking and reporting

Tech stack

  • React + HTML/CSS for the interface
  • FastAPI for the backend
  • PostgreSQL for data storage
  • PyTorch, OCR, and data tools for AI features

Critical Bugs Found in Code

🔴 BUG 1 — OTP verify endpoint does not actually verify the OTP routers/auth.py:verify_otp_endpoint checks if a user with that phone exists, not whether the OTP matches. Any phone in the DB passes verification regardless of OTP value.
🔴 BUG 2 — No business-scoping on invoice/dashboard queries routers/transactions.py:list_invoices returns ALL invoices for ALL businesses. Store owner A can read store owner B's data.
🔴 BUG 3 — OTP uses random.randint (not cryptographically secure) services/otp.py:generate_otp uses random, not secrets. An attacker can predict OTPs by observing timing patterns.
🔴 BUG 4 — No refresh token; all sessions expire silently ACCESS_TOKEN_EXPIRE_MINUTES=60 with no refresh flow means every user gets hard-logged-out every hour. No rotation, no revocation.
🔴 BUG 5 — Alembic uses synchronous engine on an async schema alembic/env.py uses engine_from_config (sync) while the app uses create_async_engine. Migrations will fail on postgresql+asyncpg:// URLs.
🔴 BUG 6 — spending.classify_transaction uses invoice_number as category hint services/spending.py tries to classify categories from invoice.invoice_number (e.g. "INV-001"). Business-generated invoice numbers contain no product keyword. Classification will always return "Other".

Multi-Tenancy Model

VyaaparKitaab is a multi-tenant SaaS. Each business is a tenant. The correct isolation model for this stage is row-level isolation via business_id enforced in all service queries plus PostgreSQL RLS policies as a backstop. Schema-per-tenant adds complexity without benefit at this scale.

3. Fixed: OTP Service

# services/otp.py — FIXED VERSION
import secrets, hashlib, json
from datetime import timedelta
from redis.asyncio import Redis

OTP_TTL_SECONDS = 300  # 5 minutes

def generate_otp() -> str:
    # secrets.randbelow is cryptographically secure (unlike random.randint)
    return f"{secrets.randbelow(1_000_000):06d}"

def _hash_otp(otp: str) -> str:
    return hashlib.sha256(otp.encode()).hexdigest()

async def store_otp(redis: Redis, phone: str, purpose: str, otp: str) -> None:
    key = f"otp:{phone}:{purpose}"
    await redis.setex(key, OTP_TTL_SECONDS, _hash_otp(otp))

async def verify_otp(redis: Redis, phone: str, purpose: str, otp: str) -> bool:
    key = f"otp:{phone}:{purpose}"
    stored_hash = await redis.get(key)
    if not stored_hash:
        return False
    ok = hmac.compare_digest(stored_hash, _hash_otp(otp))
    if ok:
        await redis.delete(key)  # OTP is one-time
    return ok

# dependencies/business.py — NEW
from fastapi import Depends, HTTPException
from sqlalchemy import select
from app.cores.database import AsyncSession, get_db
from app.models.business import Business

async def get_current_business(
    db: AsyncSession = Depends(get_db),
    user = Depends(get_current_user)
) -> Business:
    result = await db.execute(
        select(Business).where(Business.owner_id == user.id)
    )
    business = result.scalar_one_or_none()
    if not business:

7. Rate Limiting Middleware

# middleware/rate_limit.py
from fastapi import Request, HTTPException
from redis.asyncio import Redis

class SlidingWindowRateLimiter:
    def __init__(self, redis: Redis, limit: int = 60, window: int = 60):
        self.redis = redis
        self.limit = limit
        self.window = window

    async def __call__(self, request: Request, call_next):
        key = f"rl:{request.client.host}:{request.url.path}"
        count = await self.redis.incr(key)
        if count == 1:
            await self.redis.expire(key, self.window)
        if count > self.limit:
            raise HTTPException(429, "Rate limit exceeded")
        return await call_next(request)

# Tighter limits for auth endpoints (brute force protection)
# /auth/login       → 10 req/minute
# /auth/otp/send    → 3 req/5-minutes per phone
# /api/v1/*         → 120 req/minute

def run_migrations_online() -> None:
    connectable = create_async_engine(settings.DATABASE_URL)

        async with connectable.connect() as conn:
            await conn.run_sync(do_run_migrations)

Current Issues

Add: Axios Interceptor for Token Refresh

// src/lib/api.ts — upgraded
import axios from 'axios';

const api = axios.create({ baseURL: '/api/v1' });

// Attach access token from memory (not localStorage)
api.interceptors.request.use(config => {
  const token = tokenStore.getAccessToken();
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// Auto-refresh on 401
api.interceptors.response.use(
  res => res,
  async err => {
    if (err.response?.status === 401 && !err.config._retry) {
      err.config._retry = true;
      const { data } = await axios.post('/api/v1/auth/refresh', {}, { withCredentials: true });
      tokenStore.setAccessToken(data.access_token);
      return api(err.config);
    }
    return Promise.reject(err);
  }
